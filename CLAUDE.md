# Bandeiras

## Branches and deploy

Every push to `main` deploys to production on GitHub Pages (`.github/workflows/deploy.yml`).
Work on a feature branch, fast-forward it into `main` and push only when the owner approves that merge.

## Language

Player-facing copy is Portuguese. Code, comments, identifiers and commits stay English.

## Gates

`npx vitest run` and `npx tsc --noEmit`. There is no linter. CI runs `npm test` and `npm run build`, which type-checks.

## Layout

- `src/engine` holds the game rules and never touches the DOM.
- `src/ui` builds every screen with `el()` from `src/ui/dom.ts`, with no framework.
- `src/data` holds the country, capital and map data. `src/data/map.topo.json` is generated by `npm run build:map`: never read it into context.

## Player progress

Progress lives only in the player's `localStorage`, under keys prefixed `flags-quiz:`.
Changing the shape of a stored value means a new versioned key (as in `flags-quiz:quiz-records-v2`), which wipes that progress for every player: ask the owner first.

## Specs

Designs and plans live in `docs/specs/` as `YYYY-MM-DD-<topic>-design.md` and `YYYY-MM-DD-<topic>-plan.md`.
