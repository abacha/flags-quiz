# Maps Area Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Maps area beside Bandeiras where the player learns (Aprender) and fills in (Quiz) the countries of a continent on a zoomable map.

**Architecture:** A one-off Node script turns Natural Earth 1:50m map units into a committed TopoJSON keyed by our `iso2`, plus the committed exclusion list. The engine reuses `Round` with a new list of map formats and reuses `Quiz` unchanged. A single SVG map component (d3-geo projection, pointer-driven `viewBox` zoom) is shared by the map questions, the map Quiz and the map result screens.

**Tech Stack:** TypeScript, vanilla DOM, Vite 8 + vite-plugin-pwa, Vitest + happy-dom, `d3-geo`, `topojson-client`; dev only: `topojson-server`, `topojson-simplify`.

**Spec:** `docs/specs/2026-10-20-maps-design.md`

## Global Constraints

- Pool: every status of `countries.json`, minus `src/data/map-excluded.json`; one level per continent and Mundo, no tiers.
- Excluded: area of the 1:50m polygons below 100 km², no polygon in the 1:50m data, and `gb` (the four UK nations are asked instead).
- Learn: same rules as `2026-10-10-learn-choice-first-design.md`; `STARTING_LIVES` 3, `REVIEW_GAP` 5, goal `goalFor('general', pool.length)` (13/18, `MIN_GOAL` 15), `recallWeight` 3.
- Map formats: `mapToNames` (4 names), `nameToMap`, `mapPairs` (4 countries) are choice; `mapTrueFalse` and `mapTypeName` are not; only `mapTypeName` is recall. Distractors are random from the Maps pool.
- Zoom: pinch, drag and mouse wheel; maximum 24× the fitted view. Hit circle minimum on-screen radius 22 px, capped at half the distance to the nearest pool centroid.
- Projection: Equal Earth for Mundo; Mercator fitted to the pool for each continent, Europe fitted without `ru`.
- Storage keys: `flags-quiz:map-medals`, `flags-quiz:map-quiz-records`, `flags-quiz:area`. Flag keys are untouched.
- Copy (pt-BR): selector `Bandeiras` / `Mapas`; hub pill `N/6 mapas`; level card `N países`.
- Offline: the built JS chunk that holds the topology must be precached by the service worker (workbox skips files above 2 MiB by default).
- Code, identifiers and commits in English.

## Review Focus

1. A drag or pinch that ends over a country is not a tap: in `nameToMap` it would cost a life. Test in Task 4.
2. Tapping the ocean, a grey neighbour or an excluded micro territory does nothing in `nameToMap` and in the Quiz. Test in Task 4 and Task 7.
3. Countries across the antimeridian (Fiji, Kiribati, Samoa, Russia on Mundo) draw without a stripe across the whole map. Test in Task 4.
4. Tapping an already answered country in the map Quiz does nothing, like a disabled grid cell. Test in Task 7.
5. The device back button in the map Quiz asks "Encerrar o quiz?" and in the map Learn returns to the hub, like the flag screens. Test in Task 6 and Task 7.

- [ ] **Step 2: Write `scripts/build-map.mjs` and the `build:map` npm script**

The script downloads `https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_0_map_units.geojson`, assigns each feature a key, builds the topology, and writes both JSON files. Key rules, checked against the data on 2026-10-20:
- `GEOUNIT` England, Scotland, Wales, Northern Ireland → `gb-eng`, `gb-sct`, `gb-wls`, `gb-nir`.
- `GEOUNIT` Somaliland → `so`; Northern Cyprus → `cy`.
- Otherwise `ISO_A2_EH` lowercased; a key not in `countries.json` (including `-99`) becomes `id: null`.
- Several features may share a key (Portugal + Azores + Madeira, Belgium's three regions); keep them as separate geometries with the same `id`.

Excluded list: every `iso2` of `countries.json` with no geometry (today `gb`, `gi`) plus every key whose summed `d3.geoArea` × 6371.0088² is below 100 km², sorted. The script prints the list with the areas. Expected today, among others: `va`, `tk`, `tv`, `mc`, `nr`, `sm`, `gg`, `mv` (Maldives measures 66 km² at 1:50m and falls under the rule), `gi`, `gb`; `je`, `li`, `mt` stay.

Simplify with `topojson-simplify` (`presimplify` + `simplify` with a quantile weight) and quantize, keeping `src/data/map.topo.json` at or below 800 KB and Malta still recognizable.

### Task 4: Map component with zoom

**Files:**
- Create: `src/ui/map/viewBox.ts`, `src/ui/map/projection.ts`, `src/ui/map/map.ts`

**Interfaces:**
- Consumes: `topology`, `MAP_OBJECT`, `mapPool` (Task 1).
- Produces:
  - `interface ViewBox { x: number; y: number; width: number; height: number }`
  - `zoomAt(box: ViewBox, factor: number, anchor: [number, number], base: ViewBox, maxZoom: number): ViewBox` — keeps `anchor` (viewBox coordinates) fixed, clamps zoom between 1× and `maxZoom`× of `base`, keeps the box inside `base`.
  - `panBy(box: ViewBox, dx: number, dy: number, base: ViewBox): ViewBox` — clamps inside `base`.
  - `projectionFor(continent: ContinentKey, features: FeatureCollection): GeoProjection` — Equal Earth for `world`; Mercator otherwise, rotated to `[-160, 0]` for `oceania`, fitted with `fitWidth(1000, …)` to the pool features (`ru` left out of the fit for `europe`).
  - `type CountryPaint = 'idle' | 'highlight' | 'answered' | 'missed'`
  - `interface MapView { element: HTMLElement; paint(iso2: string, state: CountryPaint, label?: string): void; clear(): void }`
  - `renderMap(continent: ContinentKey, onTap?: (country: Country) => void): MapView` — draws every geometry (pool countries tappable with `data-iso2`, the rest grey with `pointer-events: none`), one invisible hit circle per pool country on top, and a ring marker on highlighted countries.
- `MAX_ZOOM = 24`, `MIN_HIT_PX = 22`, `TAP_SLOP_PX = 8` in `map.ts`.

- [ ] **Step 4: Implement `viewBox.ts`, `projection.ts` and `map.ts`, plus the map styles in `style.css`**

Pointer events on the `<svg>`: one pointer drags, two pinch (factor from the change in distance, anchor at their midpoint), the wheel zooms by 1.2 per notch at the cursor. A gesture that moved more than `TAP_SLOP_PX` swallows the following click. During a gesture only `viewBox` changes; hit circle radii, ring and label sizes are recomputed at gesture end from the current zoom. Hit circle centre: centroid of the country's largest polygon; radius `max(MIN_HIT_PX in viewBox units, own size)` capped at half the distance to the nearest other pool centroid.
